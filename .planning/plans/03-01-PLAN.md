  <name>Task 1: Implement JobService with state machine</name>
  <files>apps/vip-parse/src/services/jobs.py</files>
  <action>
Create JobService class in apps/vip-parse/src/services/jobs.py with:

1. **State constants and valid transitions:**
   - States: QUEUED, PARSING, ANALYZING, WRITING, COMPLETED, FAILED
   - Valid transitions map: queued→parsing, parsing→analyzing, analyzing→writing, writing→completed|failed, any→failed
   - Terminal states: COMPLETED, FAILED (no transitions allowed from these)

2. **create_job method:**
   - Accepts: db session, workspace_id, created_by (user_id), primary_filename, comparison_filename, primary_s3_key, comparison_s3_key
   - Calls CreditService.get_balance() first
   - If balance < 1, raise InsufficientCreditsError (create custom exception)
   - Creates ComparisonJob with state=queued, progress_percent=0
   - Returns the created job

3. **transition_state method:**
   - Accepts: db session, job_id, new_state
   - Validates transition is allowed (check current state against transitions map)
   - If terminal state, raise InvalidStateTransitionError
   - Updates state, updated_at
   - For state transitions, set appropriate progress_percent defaults:
     - parsing: 10, analyzing: 40, writing: 70, completed: 100, failed: keep current

4. **update_progress method:**
   - Accepts: db session, job_id, progress_percent, current_step (optional)
   - Updates progress_percent and current_step
   - Does NOT change state (state transitions are explicit)

5. **complete_job method:**
   - Accepts: db session, job_id, result_s3_key, narrative_s3_key (optional)
   - Transitions to COMPLETED
   - Sets completed_at, result keys
   - Calls CreditService.consume_credit(db, workspace_id, job_id, amount=1)
   - Returns updated job

6. **fail_job method:**
   - Accepts: db session, job_id, error_code, error_message
   - Transitions to FAILED
   - Sets error_code, error_message, completed_at
   - Does NOT consume credit
   - Returns updated job

7. **get_job method:**
   - Accepts: db session, job_id, workspace_id (optional for scoping)
   - Returns job or None
   - If workspace_id provided, validates job belongs to workspace

Custom exceptions at module level:
- InsufficientCreditsError(Exception)
- InvalidStateTransitionError(Exception)
- JobNotFoundError(Exception)

All methods are async and use AsyncSession.

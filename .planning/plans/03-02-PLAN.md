Create apps/vip-parse/src/routes/jobs.py with authenticated job endpoints:

1. **Router setup:**
   - `jobs_router = APIRouter(prefix="/jobs", tags=["jobs"])`

2. **POST /jobs - Create comparison job:**
   - Request body: `{ carrier_key: str, contractor_key: str, carrier_filename?: str, contractor_filename?: str }`
   - Depends on: `require_auth` from dependencies/auth.py (gets current_user)
   - Get workspace_id from current_user
   - Call JobService.create_job() - this checks credits internally
   - If InsufficientCreditsError, return 402 Payment Required with `{"error": "insufficient_credits", "message": "Not enough credits to start job"}`
   - Enqueue RQ job with the ComparisonJob.id (not a new UUID)
   - Update ComparisonJob.rq_job_id with the RQ job ID
   - Return 202 with `{"job_id": str(job.id), "status": "queued"}`

3. **GET /jobs/{job_id} - Get job status:**
   - Depends on: `require_auth`
   - Call JobService.get_job(db, job_id, workspace_id=current_user.workspace_id)
   - If job not found or not in workspace, return 404
   - Return job data: id, state, progress_percent, current_step, error_code, error_message, result_s3_key, created_at, completed_at
   - If state is completed and result_s3_key exists, generate presigned download URL (reuse pattern from bid_comp.py)

4. **POST /jobs/{job_id}/retry - Retry failed job:**
   - Depends on: `require_auth`
   - Get original job, verify it belongs to workspace and state is FAILED
   - Create NEW job with same inputs (primary/comparison keys, filenames)
   - This goes through create_job which checks credits again
   - Increment original job's retry_count (for tracking, but the new job is separate)
   - Return 202 with new job details

5. **GET /jobs - List jobs for workspace (pagination):**
   - Depends on: `require_auth`
   - Query params: page (default 1), per_page (default 20, max 100)
   - Return jobs for workspace, ordered by created_at DESC
   - Include total_count for pagination

- Add: app.include_router(jobs_router)

Use Pydantic models for request/response schemas (define in routes/jobs.py or separate schemas file).

   ```python
   def _run_async(coro):
       """Run async coroutine from sync context."""
       loop = asyncio.new_event_loop()
       try:
           return loop.run_until_complete(coro)
       finally:
           loop.close()
   ```

3. **Add progress callback function:**
   ```python
   def _update_job_progress(db_job_id: str, state: str, progress: int, step: str = None):
       """Update job progress in database."""
       async def _update():
           async with get_async_session() as db:
               if state:
                   await JobService.transition_state(db, uuid.UUID(db_job_id), state)
               await JobService.update_progress(db, uuid.UUID(db_job_id), progress, step)
       try:
           _run_async(_update())
       except Exception as e:
           logger.warning("Failed to update job progress: %s", e)
   ```

# Milestone v2.3: Report Quality

**Status:** ✅ SHIPPED 2026-03-07

## Overview

Fix the narrative regression causing empty report sections, then elevate the XLSX report to professional, client-shareable quality. Five focused phases: repair the pipeline, polish the visual output, fix prompt quality, improve overview depth, and fix the fundamental LLM routing bug that caused all line-item jobs to fall back to Python-generated text.

**Plans**: 1 plan

- [x] 18-01: Fix NarrativeResult → export_xlsx type mismatch (add overlay properties)

### Phase 22: Executive Summary Narrative

**Goal**: Remove Notes column from Analysis category table; fix Overall Summary regression (raw data fields in output); rewrite as executive-grade narrative paragraph with scope observations woven in naturally
**Depends on**: Phase 21
**Plans**: 2 plans

Plans:
- [x] 22-01: Writer prompt v2.4 — remove raw field echo, mandatory approach-pair framing
- [x] 22-02: XLSX cleanup — 5-column Analysis table, clean overall summary

**Details:**
22-01: Discovered `Overall Direction: {overall_delta_direction}` and `Confidence: {confidence}` raw fields in user prompt caused LLM to echo enum values verbatim ("Overall direction: primary_higher"). Removed fields, added anti-echo and anti-forward-reference CRITICAL RULES, made approach-pair selection mandatory via APPROACH PAIR REQUIREMENT in system prompt. Also fixed `writer_pass_v2.json` brace escaping bug — Python str.format() raised KeyError on every line-item job, falling back to Python-generated text.
22-02: Removed Notes column from Analysis table (reverted to 5-column layout). Simplified `_build_overall_summary` to return LLM prose directly (no scope suffix appended).

## Milestone Summary

**Key Decisions:**

- Use overlay properties on NarrativeResult rather than refactoring the pipeline — preserves compatibility, minimal blast radius
- Approach-pair framing as mandatory constraint in system prompt — approach-first sentence 1 must be required, not optional inspiration
- Remove raw field lines from LLM user prompt — Overall Direction/Confidence fields added no LLM value, only caused echo artifacts
- writer_pass_v2 used for all line-item jobs — v1 fix alone insufficient; both prompts needed the brace fix and prompt improvements
- Remove Notes column from Analysis sheet — Summary Top Cost Drivers table already covers notable drivers; Notes in Analysis created redundancy

**Issues Resolved:**

- Narrative pipeline regression: NarrativeResult type mismatch prevented narrative from appearing in XLSX
- writer_pass_v2 JSON schema brace escaping: KeyError crashed writer pass before LLM call on every line-item job
- Raw field echo: "Overall direction: primary_higher. See key drivers below for details." replaced by actual LLM narrative
- Overview quality: approach-pair-first framing now mandatory

**Issues Deferred:**

- 2 migration naming tests in `tests/test_migrations_constraints.py` expecting `vip30-web` service naming (unrelated)

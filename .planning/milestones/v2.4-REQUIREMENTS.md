# Requirements: VIP30 v2.4 Parser Coverage

**Defined:** 2026-03-07
**Core Value:** Reliable end-to-end bid comparison that produces actionable output

## v1 Requirements

Requirements for v2.4 Parser Coverage milestone. Goal: measure how much content the Xactimate parser actually captures before making any changes.

### Parser Audit

- [x] **AUDIT-01**: Parser audit runs all PDFs in `./docs/` through the existing parser and captures JSON output for each document
- [x] **AUDIT-02**: Audit compares parser output against PDF content for all extracted sections (summary header, line items, O&P, depreciation, metadata fields)
- [x] **AUDIT-03**: Audit maps missed line items per section/trade — count of extracted items vs. items present in PDF
- [x] **AUDIT-04**: Audit validates dollar amounts — parser-extracted totals and subtotals compared against actual PDF values
- [x] **AUDIT-05**: Audit covers all document profiles present in `./docs/`: rough drafts (contractor), final drafts (contractor), StateFarm final drafts
- [x] **AUDIT-06**: Audit findings documented per document type — rough draft gaps, contractor final gaps, and StateFarm gaps identified separately

### Golden Masters

- [x] **GOLD-01**: Golden master JSON file produced for each document type (one rough draft, one contractor final draft, one StateFarm)
- [x] **GOLD-02**: Each golden master represents the complete expected parser output — every section, every line item, every amount the parser should capture from that document type
- [x] **GOLD-03**: All golden masters human-verified against source PDFs before being locked as ground truth
- [x] **GOLD-04**: Golden masters stored in version control under `tests/golden/` (or equivalent location in `packages/parser/`)

### Coverage Harness

- [x] **HARNESS-01**: Automated test suite runs each golden-master document through the parser and diffs output against the corresponding golden master
- [x] **HARNESS-02**: Per-file test result produced — pass if output matches golden master within defined tolerance, fail with details if gaps detected
- [x] **HARNESS-03**: Field-level diff report shows exactly which fields are missing, wrong, or extra per document
- [x] **HARNESS-04**: Summary gap report produced across all tested documents — which sections and fields are consistently missing across doc types

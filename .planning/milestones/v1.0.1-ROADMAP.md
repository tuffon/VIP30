# Milestone v1.0.1: Professional Adjuster Narratives

**Status:** SHIPPED 2026-02-09
**Phases:** 1-8
**Total Plans:** 8

## Overview

Transform bid comparison narrative output from generic AI-sounding text to professional adjuster memo tone using a three-pass LLM pipeline (Analysis → Writer → Conditional Compliance Rewrite) with deterministic quality gating.

### Phase 2: Quality Gates (Deterministic)
**Goal**: Implement measurable quality checks that run without LLM calls
**Depends on**: Phase 1
**Plans**: 1 plan

Plans:
- [x] 02-01: Deterministic quality checkers (hedging, verbosity, valuation, summary)

**Details:**
Build deterministic validators that provide pass/fail signals for the conditional compliance rewrite decision.

Requirements covered:
- GATE-01: Hedging threshold check (≤3 soft qualifiers per section)
- GATE-02: Trade verbosity check (≤2 sentences per trade, avg ≤40 words)

## Milestone Summary

**Key Decisions:**
- Three-pass LLM pipeline (analysis → writer → compliance rewrite)
- Pydantic v2 BaseModel for all pipeline data contracts
- textstat for NLP sentence/word counting
- Whole-word regex matching for single-term pattern detection
- Zero tolerance default for analyst phrases and GPT-isms
- Max 2 compliance rewrite iterations to prevent infinite loops
- Content-hash cache keys using SHA256 of model_dump_json
- Case-insensitive category matching for key_driver lookup

**Issues Resolved:**
- Token count reduced from 100k+ to ~5-10k via analysis pass extraction
- AI-sounding language eliminated via quality gates
- Regression: key_drivers now have numeric values
- Regression: narrative structure improved with explicit sentence requirements

**Technical Debt Incurred:**
- None identified

# Milestone v2.1: Repository Restructure

**Status:** ✅ SHIPPED 2026-02-18
**Phases:** 13-15
**Total Plans:** 2 (Phase 13 formal plans + Phases 14-15 executed directly)

## Overview

Clean up repository organization — clear directory names for API, worker, frontend, and shared code. Split monolith into structured packages and apps. Rename Render services to match.

## Phases

### Phase 13: Package Extraction
**Goal**: Extract parser and shared Python business logic into standalone packages, remove dead code
**Depends on**: v2.0 (existing codebase)
**Requirements**: DIR-03, DIR-04, DIR-05, PKG-01, PKG-02, PKG-05
**Plans**: 2 plans in 2 waves

Plans:
- [x] 13-01: Parser package extraction + preflight cleanup (Wave 1)
- [x] 13-02: Shared-python package extraction + import updates (Wave 2)

**Success Criteria:**
1. `packages/parser/` exists as a standalone Python package with pyproject.toml
2. `packages/shared-python/` exists with pipeline, bid_comp, methodology, rules, llm modules
3. `src/preflight/` dead code removed
4. Parser package has zero dependencies on business logic
5. No circular imports between packages

### Phase 14: Directory Split & Config
**Goal**: Split monolith into api/worker apps, rename frontend, update all imports and build configs
**Depends on**: Phase 13 (packages must exist before apps can reference them)
**Requirements**: DIR-01, DIR-02, PKG-03, PKG-04, IMP-01, IMP-02, IMP-03, IMP-04
**Plans**: Executed directly (no formal PLAN.md)

**Success Criteria:**
1. `apps/api/` contains only FastAPI server code
2. `apps/worker/` contains only RQ worker code
3. `apps/frontend/` contains the Next.js app (renamed from vipclaims-saas)
4. All Python imports resolve correctly
5. Turborepo/pnpm workspace config includes new package directories
6. Frontend package.json name updated to `frontend`

### Phase 15: Render Deployment
**Goal**: Update Render service configuration and verify end-to-end deployment
**Depends on**: Phase 14 (all code must be in final locations)
**Requirements**: REN-01, REN-02, REN-03, REN-04, REN-05
**Plans**: Executed directly (no formal PLAN.md)

**Success Criteria:**
1. render.yaml `vip30-api` with correct rootDir, build, and start commands
2. render.yaml `vip30-frontend` updated for `apps/frontend/` paths
3. render.yaml `vip30-worker` updated for `apps/worker/` paths
4. `NEXT_PUBLIC_API_BASE_URL` references `vip30-api` URL
5. All services deploy and function correctly

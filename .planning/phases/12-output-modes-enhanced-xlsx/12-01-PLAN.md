  <name>Task 1: Create OutputMode enum and OutputModeFilter</name>
  <files>apps/vip-parse/src/pipeline/output_modes.py</files>
  <action>
Create new module with:

1. **OutputMode enum** (str, Enum) with 4 values:
   - `EXECUTIVE = "executive"` — 1-page compressed view
   - `CARRIER = "carrier"` — carrier negotiation focus
   - `LITIGATION = "litigation"` — strictest neutral tone, full evidence citations
   - `INTERNAL = "internal"` — full detail, all sections (default)

2. **ModeFilteredOutput dataclass**:
   - `mode: OutputMode`
   - `total_delta: float`
   - `top_drivers: List[dict]` — filtered driver list (top 3 for executive, all for others)
   - `structural_flags: List[str]` — from SignalBundle alert tags
   - `methodology_summary: Optional[str]`
   - `scope_observations: List[str]`
   - `followups: List[str]`
   - `sections: Dict[str, Any]` — full narrative sections (filtered by mode)
   - `include_methodology_sheet: bool`
   - `include_scope_sheet: bool`
   - `include_category_detail: bool`

3. **OutputModeFilter class** with static method `apply(mode: OutputMode, narrative: FinalNarrative, methodology: Optional[MethodologyResult], signal_bundle: Optional[Any]) -> ModeFilteredOutput`:
   - INTERNAL mode: all content, all sheets
   - EXECUTIVE mode: top 3 drivers only, no followups, no scope detail, only Executive Summary + Ranked Impact sheets
   - CARRIER mode: all drivers, scope observations, methodology, followups — all sheets
   - LITIGATION mode: all content, all sheets, no suggested followups (followups imply recommendations)

Key constraint: The filter NEVER changes analytical findings or dollar amounts. It only controls which sections appear and how many drivers to include. All four modes produce identical numbers for the same drivers.

Import FinalNarrative from pipeline.models, MethodologyResult from methodology.models. Use Optional typing for signal_bundle since Phase 10 may not be executed yet — if signal_bundle is None, structural_flags defaults to empty list and top_drivers comes from narrative.delta_rows sorted by absolute delta.

Rewrite the XLSX export to produce a 5-sheet workbook. Keep the existing `export_xlsx()` function signature but add optional parameters: `output_mode: Optional[OutputMode] = None`, `methodology: Optional[MethodologyResult] = None`, `audit_metadata: Optional[Dict] = None`. When output_mode is None, default to INTERNAL (full detail) for backward compatibility.

**Sheet 1: Executive Summary** (always present)
- Title row: "Bid Comparison — Executive Summary"
- Estimate names, grand totals, total delta (bold, formatted)
- Top drivers table (3 for executive mode, all for others): Category, Primary ($), Comparison ($), Delta ($), % of Total
- Structural flags section (if any from mode filter)
- Methodology summary (1-2 line overview if methodology provided)
- Self-contained: decision-maker can act from this sheet alone
- Freeze panes at A2

**Sheet 2: Ranked Impact** (skip for executive mode if ModeFilteredOutput.include_category_detail is False — actually always include this sheet, it's core)
- All categories sorted by absolute delta magnitude (largest first)
- Columns: Rank, Category, Primary ($), Comparison ($), Delta ($), % of Total Variance, Severity
- Conditional formatting:
  - Delta column: ColorScaleRule red (negative) → white (zero) → green (positive)
  - Severity column: PatternFill — red for "critical", orange for "notable", light blue for "informational"
- Freeze panes at A2

**Sheet 3: Methodology** (skip if include_methodology_sheet is False)
- O&P treatment comparison (primary vs comparison)
- Depreciation approach comparison
- Unit pricing source
- Locality factors
- Data pulled from MethodologyResult if available, otherwise "Methodology analysis not available"

**Sheet 4: Scope Alignment** (skip if include_scope_sheet is False)
- Scope observations from narrative
- Items present in one estimate but absent from the other (from narrative sections)

**Sheet 5: Category Detail** (skip if include_category_detail is False)
- Full category matrix (replaces old "Verisk Categories" sheet)
- Same data as before but with conditional formatting on delta column
- DataBarRule on delta column for visual impact sizing
- Freeze panes at A2

**Sheet 6: Audit Trail** (always present)
- Comparison parameters: primary filename, comparison filename, output mode
- Timestamps: analysis timestamp (datetime.utcnow())
- Input file hashes: accept from audit_metadata dict if provided (computed upstream)
- Pipeline version: hardcode "v2.0"

**Conditional formatting colors:**
- Critical severity: PatternFill(fill_type="solid", fgColor="FF4444")
- Notable severity: PatternFill(fill_type="solid", fgColor="FFA500")
- Informational severity: PatternFill(fill_type="solid", fgColor="ADD8E6")
- Positive delta (green): "00AA00"
- Negative delta (red): "CC0000"

Preserve the existing helper functions (_autosize, _write_text_section, etc.) where they're still useful. Remove _write_key_driver_section and _write_list_section if they're fully replaced by the new sheet structure.

Keep the old `recap_rows` parameter but make it optional (default None) since "Original Recap" sheet is replaced by "Category Detail". If recap_rows is provided but category_rows covers the same data, prefer category_rows.

Do NOT import or use any Phase 10 models (RankedImpactRow, SignalBundle, etc.) directly — accept data through the ModeFilteredOutput dataclass which provides pre-filtered content. The mode filter handles all Phase 10 integration.

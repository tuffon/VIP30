Create `src/prompts/writer_pass_v2.json` based on writer_pass_v1.json with these additions to the system prompt:

**1. Add QUANTIFICATION RULES section (top priority, before style rules):**
```
QUANTIFICATION RULES (MANDATORY — violations cause automatic rejection):
1. Every sentence referencing a difference, delta, or variance MUST include:
   - A dollar amount ($X,XXX.XX format)
   - A percentage (X.X% format)
2. Formula for amounts field: "{primary_name}: $X. {comparison_name}: $Y. Delta: $Z (XX.X%)"
3. Formula for driver narrative sentences: Include both $amount and X.X% in each comparison
4. Overview MUST reference total delta with percentage
5. Scope observations describing presence/absence are exempt from this rule
```

**2. Add EVIDENCE GROUNDING section:**
```
EVIDENCE GROUNDING (data integrity):
Data granularity for this comparison: {data_granularity}

Rules by granularity level:
- LINE_ITEM: You may reference specific items, unit prices, quantities, materials
- CATEGORY: You may ONLY reference category names and totals. Do NOT mention:
  - Specific quantities with units (e.g., "14 windows", "28 squares")
  - Unit prices (e.g., "$1,800 each", "$8/SF")
  - Specific material names with pricing
- COVERAGE: You may ONLY reference coverage types and totals
- ESTIMATE_TOTAL: You may ONLY reference the grand total

If data_granularity is not LINE_ITEM, describe categories and totals only.
```

**3. Add PROHIBITED LANGUAGE section (concise — top 20 most common per category):**
```
PROHIBITED LANGUAGE (automatic rejection if used):
Hedge words: appears, seems, might, may, could, possibly, potentially, suggests, indicates, perhaps, likely, probably, apparently, presumably, arguably, conceivably, approximately, estimated, supposedly, roughly
Judgment adjectives: excessive, inadequate, inflated, unreasonable, appropriate, insufficient, overestimated, understated, thorough, sloppy, correct, incorrect, accurate, necessary, unnecessary, justified, unjustified, fair, unfair, conservative
GPT-isms: delve, comprehensive, holistic, leverage, significantly, ultimately, essentially, furthermore, moreover, nevertheless, it's worth noting, in conclusion, moving forward
```

**4. Update STYLE RULES:**
- Change sentence 3 from "explain WHY the difference likely exists" to "state what the other estimate scopes instead — neutral observation, no causation language"
- Remove all mentions of "likely" or "suggests" being acceptable
- Add: "NEVER use qualitative comparisons. ALWAYS quantify: '$X more', '$Y less', 'a delta of $Z (X.X%)'"

**5. Update few-shot examples** to demonstrate quantified pattern:
```
BAD:  "Primary includes significantly more electrical work"
GOOD: "Apex Restoration includes electrical work totaling $12,500; Carrier Estimate scopes $4,200, a delta of $8,300 (197.6%)."
```

**6. Add user prompt context variables:**
- `{data_granularity}` — injected from MethodologyResult
- `{available_evidence}` — summary of what data is available (line items, category totals, etc.)

Keep the existing terminology glossary, loss type context, difference dimensions, and natural prose instructions. The v2 prompt extends v1, it doesn't discard the good parts.

**Keep writer_pass_v1.json unchanged** — it serves as fallback when methodology is not available.

**Prompt length concern (Pitfall 6):** Keep prohibited word lists to top 20 per category in the prompt. The full lists live in the deterministic gates. Add a summary instruction: "Your output will be checked against comprehensive prohibited word lists. The above lists are the most common violations. Avoid ALL hedge words, judgment adjectives, and GPT-isms."

**New checker classes:**

1. **HedgingChecker (GATE-01)** — Expanded from 13 → 80+ terms. Merges old GATE-01, GATE-05 (AnalystToneChecker), and GATE-06 (SlopChecker) into one checker. Uses HEDGE_WORDS + SLOP_PHRASES from quality_words.py. Zero tolerance (max_violations=0). Word boundary matching for single words, substring matching for multi-word phrases.

2. **JudgmentLanguageChecker (GATE-02)** — NEW. Uses JUDGMENT_ADJECTIVES + JUDGMENT_PHRASES from quality_words.py. Zero tolerance. Word boundary matching for adjectives, substring for phrases. See RESEARCH.md Pattern 2 for implementation.

3. **QuantificationChecker (GATE-03)** — NEW. Replaces old ValuationLinkChecker. Every sentence referencing a delta must include BOTH `$amount` AND `percentage%`. Uses DELTA_INDICATORS list to identify delta-referencing sentences, then checks for DOLLAR_PATTERN and PERCENT_PATTERN. Sentence splitting via `re.split(r'(?<=[.!?])\s+', text)`. See RESEARCH.md Pattern 3.

4. **EvidenceGroundingChecker (GATE-04)** — NEW. Uses GranularityLevel from `src/methodology/models.py`. When granularity is LINE_ITEM, all references allowed. When CATEGORY or coarser, rejects line-item-level references (unit prices like "$450/each", quantity+unit patterns like "14 windows"). See RESEARCH.md Pattern 4. Only flag patterns with specific numbers + units (conservative approach per Open Question 1).

5. **MethodologyNeutralityChecker (GATE-05)** — NEW. Uses METHODOLOGY_PROHIBITED from quality_words.py. Zero tolerance. Applied to methodology sections only. See RESEARCH.md Pattern 5.

**Reorganized QualityEvaluator:**

```python
class QualityEvaluator:
    def __init__(self):
        self.hedging = HedgingChecker()
        self.judgment = JudgmentLanguageChecker()
        self.quantification = QuantificationChecker()
        self.evidence = EvidenceGroundingChecker()
        self.methodology_neutrality = MethodologyNeutralityChecker()

    def evaluate(
        self,
        draft: DraftNarrative,
        data_granularity: Optional[GranularityLevel] = None,
        methodology_text: Optional[str] = None,
    ) -> QualityReport:
        checks = []

        # GATE-01: Hedge + slop on overview + all driver narratives
        all_narrative_text = self._collect_narrative_text(draft)
        checks.append(self.hedging.check(all_narrative_text))

        # GATE-02: Judgment on overview + all driver narratives
        checks.append(self.judgment.check(all_narrative_text))

        # GATE-03: Quantification on overview + driver narratives
        # (exempt scope_observations per Open Question 2)
        quant_text = draft.overview + " " + " ".join(d.narrative for d in draft.key_drivers)
        checks.append(self.quantification.check(quant_text))

        # GATE-04: Evidence grounding (only if granularity provided)
        if data_granularity is not None:
            checks.append(self.evidence.check(all_narrative_text, data_granularity))

        # GATE-05: Methodology neutrality (only if methodology_text provided)
        if methodology_text is not None:
            checks.append(self.methodology_neutrality.check(methodology_text))

        passed = all(c.passed for c in checks)
        return QualityReport(passed=passed, checks=checks)
```

**Backward compatibility:**
- `QualityEvaluator.evaluate(draft)` still works with just a DraftNarrative (no data_granularity or methodology_text)
- When optional params are None, GATE-04 and GATE-05 are skipped
- Old GATE-02 (VerbosityChecker) and GATE-04 (SummaryLengthChecker) are removed — they were presentation concerns, not defensibility concerns

**Helper method:**
```python
def _collect_narrative_text(self, draft: DraftNarrative) -> str:
    parts = [draft.overview]
    parts.extend(d.narrative for d in draft.key_drivers)
    parts.extend(draft.scope_observations)
    return " ".join(parts)
```

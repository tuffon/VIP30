```
## Ranked Impact Context (pre-analyzed, do not contradict)
Top variance categories by impact:
```

**Part B: Enrich writer pass with alert and follow-up context** (`src/pipeline/passes/writer.py`)

When PipelineState has signals (not None), append two sections to the writer prompt context:

```
## Alert Tags (must be mentioned in narrative)
{for each alert in alert_tags:}
  - [{severity}] {title}: {detail} {affected_amount if not None}
{end}

## Structural Patterns (weave into analysis narrative)
{for each pattern in structural_patterns:}
  - {pattern_type}: {description}
    Evidence: {evidence joined}
{end}

## Diagnostic Follow-Ups (include as next steps section)
{for each followup in diagnostic_followups:}
  - [{priority}] {action} (triggered by: {trigger})
{end}
```

Add to the system prompt: "Alert Tags must appear in the narrative — each alert represents a verified analytical finding. Structural Patterns should be referenced when explaining why deltas exist.

  <action>
    Update the vip30-frontend service's NEXT_PUBLIC_API_BASE_URL environment variable to reference the vip30-web service URL dynamically.

    Render supports referencing other services using fromService with property: host or property: connectionString.

    The backend is at vip30-web service. Update the envVar to:
    ```yaml
    - key: NEXT_PUBLIC_API_BASE_URL
      fromService:
        name: vip30-web
        type: web
        property: hostport
    ```

    Note: Render's `hostport` property returns the full URL like `https://vip30-web.onrender.com`. If that doesn't work, use the pattern:
    - Set a sync:false placeholder and document that user must set it to the backend URL after first deploy.

    Alternative if dynamic reference doesn't work: Set the value explicitly to the known backend URL pattern.
  </action>

2. Start from the parser's existing JSON output (which correctly captures estimate_name, case_metadata, grand_total_areas, recaps_and_summaries):
   - Load: `packages/parser/audit_output/final-drafts/BSchacter-02.12.26-Est-JVB-RepairEstimate-$809,464.83.json`
3. Use pdfplumber to extract section structure from the PDF:
   - PDF: `docs/final-drafts/BSchacter-02.12.26-Est-JVB-RepairEstimate-$809,464.83.pdf`
   - Identify section headers (typically bold text or lines with no indentation followed by a section name)
   - For each section: extract its declared total from the section subtotal row
   - Extract line items if identifiable from text layout (Description | amounts pattern)
   - If line items cannot be reliably extracted from text, document sections with their declared totals and empty line_items lists (the section-level data is the primary gap finding)
4. Construct the golden master JSON with the sections integrated into the existing parser output structure
5. Validate that grand_total ($809,462.41 or $809,464.83 — confirm from PDF) is consistent with section totals
6. Write to `packages/parser/tests/golden/final-drafts/bschacter.golden.json` (encoding='utf-8', indent=2)

```json

```

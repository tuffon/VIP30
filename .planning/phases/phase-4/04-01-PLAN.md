**In passes/analysis.py:**

1. **AnalysisInput** Pydantic model for pass input:
   ```python
   class AnalysisInput(BaseModel):
       primary_name: str
       comparison_name: str
       primary_totals: Dict[str, float]  # category -> total
       comparison_totals: Dict[str, float]
       top_deltas: List[Dict[str, Any]]  # from BidComp._top_deltas
       primary_sample_items: Dict[str, List[Dict[str, Any]]]  # category -> sampled items
       comparison_sample_items: Dict[str, List[Dict[str, Any]]]
   ```

2. **sample_line_items(payload: Dict, categories: List[str], max_per_category: int = 5):**
   - Extract line items from estimate payload (look in payload["sections"] or payload["line_items"])
   - For each category, sort items by amount (descending) and take top N
   - Return Dict[category, List[item]] where item has {description, quantity, unit, amount}
   - Handle missing/malformed data gracefully (return empty dict/list)

3. **build_analysis_input(pair: EstimatePair, top_deltas: List[Dict]) -> AnalysisInput:**
   - Extract primary/comparison names
   - Build category totals from top_deltas
   - Call sample_line_items for both estimates
   - Return populated AnalysisInput

4. **run_analysis_pass(pair: EstimatePair, top_deltas: List[Dict], llm_adapter: LLMAdapterBase) -> AnalysisResult:**
   - Build AnalysisInput from pair and top_deltas
   - Call llm_adapter.generate("analysis_pass_v1", context)
   - Parse JSON response into AnalysisResult
   - Handle parsing errors: log warning, return fallback AnalysisResult with confidence="low"
   - Log input token estimate and response details

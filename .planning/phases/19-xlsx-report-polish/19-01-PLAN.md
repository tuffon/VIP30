**3a. Improve column width strategy (XLSX-03)**

Replace `_autosize()` with a smarter version that:
1. Measures all non-merged cells per column
2. Sets column-specific minimums based on expected content

```python
_MIN_COL_WIDTHS = {
    1: 38,  # Category / label column — longest Verisk name is 44 chars; set 38 as base
    2: 16,  # Currency columns
    3: 16,
    4: 16,
    5: 16,  # Percentage or wide header
    6: 14,  # Severity
}

def _autosize(ws) -> None:
    for col_idx, column_cells in enumerate(ws.columns, start=1):
        letter = get_column_letter(column_cells[0].column)
        # Only measure unmerged cells (merged cells have value only in top-left)
        max_len = max(
            (len(str(cell.value)) for cell in column_cells
             if cell.value is not None and not isinstance(cell, type(None))),
            default=0,
        )
        min_width = _MIN_COL_WIDTHS.get(col_idx, 12)
        ws.column_dimensions[letter].width = min(max(min_width, max_len + 3), 90)
```

**Note:** The column index in `enumerate(ws.columns, start=1)` gives 1-based index for the `_MIN_COL_WIDTHS` lookup. The existing code uses `column_cells[0].column` for the letter, which is correct.

def _configure_print(ws) -> None:

Add the contractor-final line item regex pattern to constants.py.

Contractor-final line items are SINGLE lines with format:
  `{num}. {description} {QTY} {UNIT} {v1} {v2} {v3} {v4} {v5}`

Examples from BSchacter.out:
  `1. General Demolition (Bid Item) 1.00 EA 100,000.00 0.00 0.00 20,000.00 120,000.00`
  `8. Floor protection - heavy paper and 1,000.00 SF 0.00 0.71 6.83 143.36 860.19`
  `13. R&R Batt insulation - 4" - R13 - 2,325.54 SF 0.37 1.30 176.86 812.12 4,872.63`

The pattern always has 5 dollar amounts: val1-val5. The last is always TOTAL, the
second-to-last is O&P. The first three are RESET/REMOVE/REPLACE unit costs or
REMOVE/REPLACE/TAX depending on the item. This plan extracts all 5 and maps the
last three (val3, val4, val5) to replace/op/total for consistency.

Add after LINE_ITEM_HEADER_PATTERN (line 12):

```python
# Contractor-final (family C) single-line item: "{N}. {description} {QTY} {UNIT} {amounts...}"
# Description is non-greedy to stop at first decimal+unit combo.
# Groups: (1)item_num (2)description (3)qty (4)unit (5)v1 (6)v2 (7)v3 (8)v4 (9)v5
# Typically 5 amounts: RESET_unit, REMOVE_unit, REPLACE_or_TAX, O&P, TOTAL
# Minimum 3 amounts required (some items may have fewer non-zero values shown).
CFINAL_ITEM_PATTERN = (
    r'^(\d+)\.\s+'           # group 1: item number
    r'(.*?)\s+'              # group 2: description (non-greedy, stops at first QTY match)
    r'([\d,]+\.\d+)\s+'     # group 3: QTY (decimal, may have commas e.g. 1,897.79)
    r'([A-Z]{1,6})\s+'      # group 4: UNIT (1-6 uppercase letters e.g. EA, MO, SF, HR)
    r'([\d,]+\.\d{2})'      # group 5: val1 (required)
    r'(?:\s+([\d,]+\.\d{2}))?'   # group 6: val2 (optional)
    r'(?:\s+([\d,]+\.\d{2}))?'   # group 7: val3 (optional)
    r'(?:\s+([\d,]+\.\d{2}))?'   # group 8: val4 (optional)
    r'(?:\s+([\d,]+\.\d{2}))?'   # group 9: val5 (optional, typically TOTAL)
    r'\s*$'
)
```

Also add 'CFINAL_ITEM_PATTERN' to the `__all__` list at the end of the file.

**Change 3: Add _parse_cfinal_line() method**

Add the new method after `_parse_layout_a_line()` (around line 801, after its closing brace).

The method parses a single-line contractor-final item:
  `{num}. {description} {qty} {unit} {v1} {v2} {v3} {v4} {v5}`

Column mapping for the 5 amounts (based on analysis of BSchacter.out):
- v1: RESET (unit cost, may be 0)
- v2: REMOVE (unit cost, may be 0)
- v3: REPLACE or TAX (context-dependent; both map to replace/tax fields)
- v4: O&P (overhead and profit)
- v5: TOTAL (section-verified against Totals: line)

When fewer than 5 amounts present (e.g., only 3): last = TOTAL, second-to-last = O&P.

```python
def _parse_cfinal_line(self, line: str, columns: TableColumns) -> Optional[dict]:
    """Parse a contractor-final (family C) single-line item.

    Format: {num}. {description} {qty} {unit} {v1} ... {v5}
    All financial data is on ONE line (no separate calc line like family B).
    """
    raw = line.strip()
    if not raw:
        return None
    m = re.match(CFINAL_ITEM_PATTERN, raw)
    if not m:
        return None

    num = int(m.group(1))
    description = (m.group(2) or '').strip()
    qty_str = m.group(3) or '0'
    unit = (m.group(4) or '').upper()

    # Collect all matched amount groups (groups 5-9)
    raw_amounts = [m.group(i) for i in range(5, 10) if m.group(i) is not None]
    amounts = [money_to_float(a) for a in raw_amounts]

    if not amounts:
        return None

    # Map amounts: last=TOTAL, second-to-last=O&P, others=RESET/REMOVE/REPLACE or TAX
    total = amounts[-1] if len(amounts) >= 1 else 0.0
    op = amounts[-2] if len(amounts) >= 2 else 0.0
    # Middle amounts (if present) map to reset, remove, replace in order
    middle = amounts[:-2] if len(amounts) > 2 else []
    reset_val = money_to_float(middle[0]) if len(middle) > 0 else None
    remove_val = money_to_float(middle[1]) if len(middle) > 1 else None
    replace_val = money_to_float(middle[2]) if len(middle) > 2 else None

    item = {
        'type': 'line_item',
        'line_number': num,
        'description': description,
        'qty': float(money_to_float(qty_str)),
        'unit': unit,
        'reset': format_dollar_amount(reset_val) if reset_val is not None else None,
        'remove': format_dollar_amount(remove_val) if remove_val is not None else None,
        'replace': format_dollar_amount(replace_val) if replace_val is not None else None,
        'tax': None,
        'op': format_dollar_amount(op),
        'total': format_dollar_amount(total),
        'total_note': None,
        'notes': '',
    }
    return item
```

Important: the `middle` amounts are already floats (via `money_to_float`), so the

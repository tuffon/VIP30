# 34.1-02 Summary

## Outcome

Aligned BidComp analysis rows and deterministic driver-item mapping to the exact parsed category titles so visible output no longer reintroduces umbrella categories.

## What Changed

- `core.py`
  - category tables now derive categories from the exact `TradeContext` key set instead of iterating a fixed synthetic category order
  - category rows are sorted by absolute delta and then normalized label for deterministic output
  - legacy `_aggregate_categories()` now preserves exact labels and skips rollup subtotal rows
- `cost_drivers.py`
  - fallback item mapping now resolves raw line-item `cat` codes to exact estimate category titles instead of umbrella categories
  - trade-summary-backed items remain preferred when available
- `test_cost_drivers.py`
  - updated driver tests to the exact-label contract
  - added regression coverage proving selected drivers do not include umbrella labels
- `test_cost_driver_pipeline.py`
  - added regression coverage proving BidComp category rows do not include umbrella labels

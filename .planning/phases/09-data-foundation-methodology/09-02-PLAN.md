**Part A: Add structured output method to LLM adapter** (`src/llm/adapter.py`)

Add a new method to `OpenAIChatAdapter` alongside existing `generate()`:

```python
from pydantic import BaseModel
from typing import Type, TypeVar

T = TypeVar("T", bound=BaseModel)

def generate_structured(self, template_id: str, context: dict, response_model: Type[T]) -> T:
    """Generate LLM response with guaranteed schema compliance via Structured Outputs."""
    template = self.registry.get(template_id)
    messages = self._build_messages(template, context)

    completion = self.client.beta.chat.completions.parse(
        model=self.model,
        messages=messages,
        response_format=response_model,
        temperature=0.2,
        timeout=180,
    )

    result = completion.choices[0].message
    if result.refusal:
        raise ValueError(f"LLM refused structured output: {result.refusal}")

    return result.parsed
```

Also add to `LLMAdapterBase` as abstract method with NotImplementedError default (backward compat).

Keep the existing `generate()` method working — it's still used by writer and compliance passes. The migration is incremental: analysis pass first, others later.

OpenAI Structured Outputs requires all fields be required (no defaults). Create separate "LLM response" models distinct from internal models:

```python
class LLMCategoryAnalysis(BaseModel):
    """LLM response model for single category analysis. All fields required for Structured Outputs."""
    category: str
    primary_amount: float
    comparison_amount: float
    delta: float
    delta_drivers: list[str]
    line_item_evidence: list[str]

class LLMAnalysisResult(BaseModel):
    """LLM response model for analysis pass. All fields required for Structured Outputs."""
    category_analyses: list[LLMCategoryAnalysis]
    scope_gaps: list[str]
    overall_delta_direction: str  # "primary_higher" | "comparison_higher" | "similar"
    confidence: str  # "high" | "medium" | "low"
```

Use `Union[str, None]` pattern (not `Optional[str]`) for nullable fields if any are needed.

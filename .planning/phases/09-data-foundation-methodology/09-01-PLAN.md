- `MatchMethod(str, Enum)`: ACTIVITY_CODE, CAT_SEL, EXACT, ALIAS, FUZZY, UNMATCHED — how line items were matched

**Core provenance:**
- `DataProvenance(BaseModel)`: claim_id (str, deterministic hash), source_estimate (Literal["primary", "comparison"]), granularity (GranularityLevel), source_field (str, JSON path like "sections[2].line_items[5].total"), raw_value (str, exact value from parsed data)

**Methodology models:**
- `OPStructure(BaseModel)`: has_general_op (bool), general_op_pct (Optional[float]), has_per_line_op (bool), op_items_total (Optional[float]), non_op_items_total (Optional[float]), overhead_total (Optional[float]), profit_total (Optional[float]), depreciate_op (Optional[bool]), structure_type (OPStructureType), provenance (List[DataProvenance])
- `DepreciationMethodology(BaseModel)`: is_acv (bool), depreciate_material (Optional[bool]), depreciate_non_material (Optional[bool]), depreciate_taxes (Optional[bool]), depreciate_removal (Optional[bool]), depreciate_op (Optional[bool]), price_list (Optional[str]), provenance (List[DataProvenance])

**Line matching models:**

**Scope alignment:**
- `ScopeAlignmentEntry(BaseModel)`: description (str), amount (float), section_name (str), estimate (Literal["primary", "comparison"]), provenance (DataProvenance)
- `ScopeAlignmentMatrix(BaseModel)`: primary_only (List[ScopeAlignmentEntry]), comparison_only (List[ScopeAlignmentEntry]), primary_only_total (float), comparison_only_total (float)

**Delta breakdown:**
- `CategoryDelta(BaseModel)`: category (str), primary_amount (float), comparison_amount (float), delta (float), abs_delta (float), pct_of_total_variance (float), provenance (List[DataProvenance])
- `DeltaBreakdown(BaseModel)`: total_primary (float), total_comparison (float), total_delta (float), categories (List[CategoryDelta]) — sorted by abs_delta descending

**Top-level result:**

**Part B: Build MethodologyAnalyzer in `src/methodology/analyzer.py`**

Create class `MethodologyAnalyzer` with method `analyze(primary_payload: dict, comparison_payload: dict) -> MethodologyResult`.

The analyzer orchestrates 5 sub-analyses. All are methods on the class (not separate files — keep it simple):

1. `_detect_op_structure(payload: dict, estimate_label: str) -> OPStructure`:
   - Read `recaps_and_summaries.recap_by_category` for "O&P ITEMS" and "NON-O&P ITEMS" groups (use taxonomy.canonicalize_group())
   - Read `case_metadata.line_item_totals.overhead_profit` for O&P total
   - Read `case_metadata` for `depreciate_op` flag
   - Determine structure_type: GENERAL if O&P Items group exists with total, PER_LINE if individual line items have O&P column, NONE if no O&P detected
   - Create DataProvenance for each data point extracted

2. `_detect_depreciation(payload: dict, estimate_label: str) -> DepreciationMethodology`:
   - Read `case_metadata` for depreciate_material, depreciate_op, depreciate_non_material, depreciate_taxes, depreciate_removal flags
   - Read `coverage` dict for ACV detection: if any coverage has depreciation_pct > 0, it's ACV
   - Read `case_metadata.price_list` for price list name
   - Create DataProvenance for each extracted field

3. `_match_line_items(primary_payload: dict, comparison_payload: dict) -> List[LineItemMatch]`:
   - Extract line items from `sections[].line_items[]` for both estimates
   - Build label lists with section context
   - For activity code matching: extract CAT/SEL/ACT from line item descriptions if available (check if description matches LINE_ITEM_PATTERN from constants.py)
   - Use HeuristicMatcher.match_sets() for description matching
   - Convert MatchResult to LineItemMatch with provenance
   - Calculate delta for matched pairs
   - Sort results by section, then by index for determinism

4. `_build_scope_alignment(line_matches: List[LineItemMatch]) -> ScopeAlignmentMatrix`:
   - Filter unmatched items from primary → primary_only
   - Filter unmatched items from comparison → comparison_only
   - Calculate totals for each side
   - Sort each list by amount descending

5. `_build_delta_breakdown(primary_payload: dict, comparison_payload: dict) -> DeltaBreakdown`:
   - Use the same CATEGORY_KEYWORDS and VERISK_CATEGORY_ORDER from BidComp (import from core.py or duplicate the mapping)
   - Aggregate category totals from `recaps_and_summaries.recap_by_category.subtotals` for both estimates
   - Calculate per-category delta and abs_delta
   - Calculate pct_of_total_variance = abs_delta / sum(all abs_deltas) * 100
   - Sort categories by abs_delta descending
   - Create DataProvenance linking each category to its recap source

**Main `analyze()` method orchestrates all 5, determines overall `data_granularity` (LINE_ITEM if sections have line items, CATEGORY if only recap exists), and returns MethodologyResult.

**Critical rules:**
- NEVER fabricate data not in payload — if a field is missing, use None
- All float calculations use round(x, 2)
- Sort all lists before returning for determinism (DATA-06)
- Log warnings for missing data (don't error — graceful degradation)
- Import from existing modules: taxonomy.canonicalize_group, normalize.normalize_label, matchers.HeuristicMatcher
  </action>

```python
class WriterInput(BaseModel):
    primary_name: str
    comparison_name: str
    category_analyses: List[Dict[str, Any]]  # serialized CategoryAnalysis list
    scope_gaps: List[str]
    overall_delta_direction: str
    confidence: str
```

**build_writer_input(analysis: AnalysisResult, primary_name: str, comparison_name: str) -> WriterInput:**
- Convert AnalysisResult to WriterInput
- Serialize category_analyses to dict format for prompt injection
- Return populated WriterInput

**run_writer_pass(analysis: AnalysisResult, primary_name: str, comparison_name: str, llm_adapter: LLMAdapterBase) -> DraftNarrative:**
- Build WriterInput from analysis result
- Call llm_adapter.generate("writer_pass_v1", context)
- Parse JSON response into DraftNarrative
- Handle parsing errors: log warning, return minimal DraftNarrative with overview="Analysis complete. See details below."
- Log input and response details

**_parse_writer_response(raw_response: str) -> DraftNarrative:**
- Strip code fences from LLM response
- Parse JSON into DraftNarrative fields
- Build DriverNarrative objects for each key_driver
- Return validated DraftNarrative

<task type="auto">
  <name>Task 2: Create writer_pass_v1 prompt template</name>
  <files>apps/vip-parse/src/prompts/writer_pass_v1.json</files>
  <action>
Create `writer_pass_v1.json` prompt template with:

**System prompt content:**
1. Role: Professional insurance claims adjuster writing internal memos
2. **Terminology glossary** (critical for STYLE-02):
   ```
   TERMINOLOGY (use these abbreviations naturally, do not explain):
   - PWI: Preliminary Water Investigation (mitigation/drying work)
   - MEP: Mechanical, Electrical, Plumbing
   - ELE: Electrical
   - PNT: Paint
   - SF: Square Feet
   - O&P: Overhead & Profit
   ```
3. **Style rules:**
   - Short, declarative sentences (2-3 max per driver)
   - Always include dollar amounts
   - Use comparative framing: "Carrier: $X. Contractor: $Y. Delta: $Z."
   - Use action verbs: "fails to include", "does not contemplate", "drives variance"
   - No hedging: avoid "may", "might", "appears", "suggests"

4. **Few-shot examples** (critical for STYLE-01) - include 3-5 real adjuster memo excerpts:

Example 1:
"Large delta on mitigation. Carrier PWI allowance: $2,340. Contractor estimate: $8,450. Variance $6,110. Need itemized breakdown of mitigation scope."

Example 2:
"Apex fails to include MEP allowance. Carrier estimate: $14,200 MEP per unit. Contractor does not contemplate mechanical/electrical work. Delta: $56,800 across 4 units."

Example 3:
"ELE scope mismatch. Carrier: panel upgrade + 12 circuits ($4,800). Contractor: service upgrade only ($1,200). Delta $3,600. Need clarification on ELE scope."

Example 4:
"PNT coverage differs. Carrier: 1,850 SF interior repaint ($2,775). Contractor: 980 SF touch-up only ($735). Delta driven by scope, not rate."

Example 5:
"O&P treatment inconsistent. Carrier applies 20% O&P to all trades. Contractor applies O&P to subs only. Review O&P methodology."

**User prompt:**
- Include primary_name, comparison_name
- Include structured analysis (category deltas, scope gaps)
- Request JSON output matching DraftNarrative schema:
  ```json
  {
    "overview": "2-3 sentence summary",
    "key_drivers": [
      {"category": "...", "amounts": "$X vs $Y", "narrative": "..."}
    ],
    "scope_observations": ["..."],
    "suggested_followups": ["..."]
  }
  ```

<objective>
Update writer_pass_v1 prompt from v2.3 to v2.4 to fix one critical quality regression:

The user prompt template sends `Overall Direction: {overall_delta_direction}` and `Confidence: {confidence}` as raw data fields. The LLM receives values like `primary_higher` and echoes them verbatim into the overview — producing text like "Overall direction: primary_higher. See key drivers below for details." instead of a professional narrative paragraph.

Fix: Remove the raw `Overall Direction` and `Confidence` lines from the user prompt (the LLM has full category data and can infer direction from amounts). Add explicit prohibition against echoing field labels, raw enum values, or forward references.

Output: Both writer_pass_v1.json files updated to v2.4.
</objective>

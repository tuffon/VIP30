<task type="auto">
  <name>Task 2: Create auth utilities with session persistence</name>
  <files>apps/vipclaims-saas/lib/auth.ts</files>
  <action>
    Create lib/auth.ts with utilities:

    Constants:
    - AUTH_STORAGE_KEY = "vip_auth_session"
    - API_BASE (import from existing config or env)

    Functions:
    1. persistSession(email: string): void
       - Store { email, timestamp } in localStorage
       - Used after successful /auth/me response

    2. getPersistedSession(): { email: string; timestamp: number } | null
       - Read from localStorage
       - Return null if not found or invalid JSON

    3. clearPersistedSession(): void
       - Remove from localStorage
       - Called on sign out

    4. isSessionValid(session: { timestamp: number }): boolean
       - Check if timestamp is within 7 days (or configurable)
       - Used for quick "likely logged in" check before /auth/me

    Note: This is NOT replacing cookie auth. It's a client-side cache to:
    - Avoid flash of logged-out state on page load
    - Enable instant email display before /auth/me completes
    - Server cookie remains source of truth
  </action>
  <verify>npm run build passes, functions export correctly</verify>
  <done>Auth utilities created for session persistence</done>
</task>

**NarrativePipeline** class:
```python
class NarrativePipeline:
    """
    Orchestrates the three-pass narrative generation pipeline.

    Pass sequence:
    1. Analysis pass: Extract structured deltas from estimates
    2. Writer pass: Generate adjuster-tone draft narrative
    3. Quality check: Run deterministic quality gates
    4. Compliance pass: Rewrite if quality fails (max 2 iterations)

    Usage:
        pipeline = NarrativePipeline(llm_adapter)
        state = pipeline.run(pair, top_deltas, primary_name, comparison_name)
        final_narrative = state.final
    """

    MAX_REWRITE_ITERATIONS = 2

    def __init__(
        self,
        llm_adapter: LLMAdapterBase,
        quality_evaluator: Optional[QualityEvaluator] = None
    ):
        self.llm_adapter = llm_adapter
        self.evaluator = quality_evaluator or QualityEvaluator()
        self.logger = logging.getLogger("vip-parse.pipeline")

    def run(
        self,
        pair: Any,  # EstimatePair - use Any to avoid circular import
        top_deltas: List[Dict[str, Any]],
        primary_name: str,
        comparison_name: str
    ) -> PipelineState:
        """
        Execute the full pipeline and return PipelineState with results.
        """
        state = PipelineState(pair=pair, top_deltas=top_deltas)

        # Pass 1: Analysis
        state = self._run_analysis(state, primary_name, comparison_name)
        if state.analysis is None:
            return self._finalize_with_error(state, "analysis_failed")

        # Pass 2: Writer
        state = self._run_writer(state, primary_name, comparison_name)
        if state.draft is None:
            return self._finalize_with_error(state, "writer_failed")

        # Quality check
        state = self._check_quality(state)

        # Pass 3: Conditional Compliance (max 2 iterations)
        if not state.quality_passed():
            state = self._run_compliance_loop(state, primary_name, comparison_name)
        else:
            state.mark_pass_executed("compliance_skipped")
            self.logger.info("Quality passed, skipping compliance rewrite")

        # Finalize
        state = self._finalize(state)
        return state
```

**_run_analysis(state, primary_name, comparison_name) -> PipelineState:**
- Record start time
- Call run_analysis_pass(state.pair, state.top_deltas, self.llm_adapter)
- Record timing in state.pass_timings_ms
- Handle exceptions: log error, add to state.errors
- Mark pass executed
- Return updated state

**_run_writer(state, primary_name, comparison_name) -> PipelineState:**
- Record start time
- Call run_writer_pass(state.analysis, primary_name, comparison_name, self.llm_adapter)
- Record timing in state.pass_timings_ms
- Handle exceptions: log error, add to state.errors
- Mark pass executed
- Return updated state

**_check_quality(state) -> PipelineState:**
- Record start time
- Call self.evaluator.evaluate(state.draft)
- Store result in state.quality_report
- Record timing in state.pass_timings_ms
- Log quality result (passed/failed, which gates failed)
- Return updated state

**_run_compliance_loop(state, primary_name, comparison_name) -> PipelineState:**
- Loop up to MAX_REWRITE_ITERATIONS:
  - Record start time
  - Call run_compliance_pass(state.draft, state.quality_report, primary_name, comparison_name, self.llm_adapter)
  - Update state.draft with rewritten draft
  - Record timing (append iteration number)
  - Mark pass executed as "compliance_rewrite_N"
  - Re-check quality
  - If quality passes, break loop
- Log final quality status
- Return updated state

**_finalize(state) -> PipelineState:**
- If quality passed: wrap draft as FinalNarrative with rewrites_performed=0
- If compliance ran: wrap draft as FinalNarrative with rewrites_performed=N
- Set state.final
- Return updated state

**_finalize_with_error(state, error_type) -> PipelineState:**
- Create minimal FinalNarrative with error indicator
- Log error details
- Return updated state

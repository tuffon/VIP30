<task type="auto">
  <name>Task 1: Create pipeline module with Pydantic models</name>
  <files>apps/vip-parse/src/pipeline/__init__.py, apps/vip-parse/src/pipeline/models.py</files>
  <action>
Create new `pipeline` module in `apps/vip-parse/src/`.

In `models.py`, define these Pydantic models using BaseModel:

1. **CategoryAnalysis** - Analysis of a single category delta:
   - category: str
   - primary_total: float
   - comparison_total: float
   - delta: float
   - delta_drivers: List[str] (e.g., "3 window units at $450/each missing")
   - line_item_evidence: List[str] (specific items cited)

2. **AnalysisResult** - Output of analysis pass:
   - category_analyses: List[CategoryAnalysis]
   - scope_gaps: List[str] (missing trades, allowances)
   - overall_delta_direction: Literal["primary_higher", "comparison_higher", "similar"]
   - confidence: Literal["high", "medium", "low"]

3. **DriverNarrative** - Narrative for a single cost driver:
   - category: str
   - amounts: str (e.g., "$12,500 vs $8,200")
   - narrative: str (e.g., "Delta driven by...")

4. **DraftNarrative** - Output of writer pass:
   - overview: str (2-3 sentences)
   - key_drivers: List[DriverNarrative]
   - scope_observations: List[str]
   - suggested_followups: List[str]

5. **QualityCheckResult** - Result of a single quality check:
   - check_name: str
   - passed: bool
   - details: str (e.g., "Found 5 hedge words (max: 3)")

6. **QualityReport** - Aggregated quality gate results:
   - passed: bool
   - checks: List[QualityCheckResult]
   - failed_checks: List[str] (convenience property)
   - checked_at: datetime

7. **FinalNarrative** - Output of compliance pass (extends DraftNarrative):
   - Inherits all DraftNarrative fields
   - quality_report: QualityReport
   - rewrites_performed: int = 0

Use Pydantic v2 syntax (model_config, Field validators). Add docstrings explaining each model's role in the pipeline.

In `__init__.py`, export all models.
  </action>
  <verify>
    python -c "from apps.vip_parse.src.pipeline import AnalysisResult, DraftNarrative, FinalNarrative, QualityReport"
  </verify>
  <done>All 7 models importable, type hints correct, docstrings present</done>
